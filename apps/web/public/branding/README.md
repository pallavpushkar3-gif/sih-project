# Official marks

The header shows two marks in the top-left corner on every screen:

| File | Mark |
|---|---|
| `mod-crest.png` | Ministry of Defence emblem |
| `dssc-crest.png` | Defence Services Staff College crest |

Place the **authorised** artwork here as transparent PNGs (at least 64 × 64 px). The header renders them at 32 × 32 px in monochrome: white/slate in the dark theme and slate in the light theme. Until a file is present, a neutral placeholder is shown; the application never draws an imitation of an official mark.

Use of national and service emblems is restricted. In India, for example, the State Emblem of India (Prohibition of Improper Use) Act, 2005 applies. Only add artwork you are authorised to use for this project.
